# 平均股价 · ETF 轮动监控

基于通达信"平均股价"指数（880003）MACD-DIF 拐点信号，在中证2000增强ETF（159552）与红利低波ETF（512890）之间轮动的量化分析与本地监控网站（2024-06-28 之前的历史进攻仓为中证1000ETF 512100）。

> 防守仓已于 2026-08 由红利ETF（510880）切换为红利低波ETF（512890），见下文「防守仓切换」一节；
> 进攻仓已于 2026-08 由中证1000ETF（512100）切换为中证2000增强ETF（159552，2024-06-28 上市），
> 历史区间采用拼接口径，见下文「进攻仓切换」一节；
> 历史回测表（方案A/B/C）仍为 510880 口径。

## 策略逻辑（方案B · 对称信号）

信号基于平均股价的 MACD-DIF（参数 12/26/9，与通达信公式一致）：

- **买入信号**：DIF 零轴下方拐头向上 → 卖出红利低波ETF，买入中证1000ETF
- **卖出信号**：DIF 拐头向下（任意位置）→ 卖出中证1000ETF，买入红利低波ETF
- 信号 T 日收盘产生，T+1 开盘价成交

> 注：文中的"中证1000ETF"为历史进攻仓；2024-06-28 起进攻仓已切换为中证2000增强ETF（159552），
> 见「进攻仓切换」一节。

## 方案C · 慢速 DIF 拐点（参数寻优结果）

规则与方案B 完全相同，唯一区别是 DIF 参数由 12/26 放慢为 **17/34**（DEA 不参与拐点判断）：

- **买入信号**：DIF(17,34) 零轴下方拐头向上 → 卖出红利ETF，买入中证1000ETF
- **卖出信号**：DIF(17,34) 拐头向下（任意位置）→ 卖出中证1000ETF，买入红利ETF

由 `optimize.py` 网格搜索（1152 组参数）得出；邻域参数（18/32、19/30、20/28 等）收益均在
360~390%，非孤立尖峰。样本外（2021-08 后）年化 28.8%、最大回撤 -20.3%，优于全区间表现。
注意：参数系同一段历史内寻优，存在过拟合风险，仅供参考。

**当前网站（`site/`）展示的信号与换仓明细已切换为方案C**（`export_json.py` 使用 17/34/9）；
`backtest.py` 默认参数仍为 12/26/9，方案B 可由 `compare.py` 复现。

## 进攻仓切换：512100 中证1000 → 159552 中证2000增强

2026-08 起进攻仓由中证1000ETF（512100）切换为中证2000增强ETF招商（159552，2024-06-28
上市）。因 159552 上市较晚，网站与回测采用**拼接口径**：2024-06-28 之前进攻腿=512100
（历史不变），之后=159552；回测窗口仍为 2019-01-18（512890 上市）起。

切换依据（`compare_variants.py` 对比三，同一方案C 信号、同一窗口 2024-06-28 起约 26 个月，
含双边万1佣金；窗口偏短，仅供参考）：

| 进攻腿 | 累计收益 | 年化 | 最大回撤 |
|---|---|---|---|
| 159552 中证2000增强 | 140.5% | 50.8% | -16.2% |
| 563300 中证2000ETF | 118.8% | 44.3% | -16.8% |
| 512100 中证1000ETF | 113.8% | 42.7% | -17.7% |

同窗口 159552 买入持有相对 563300 的超额约 +51 个百分点（增强 alpha），且该窗口内
159552 买入持有（136.0%）已接近其轮动收益（140.5%）——优势主要来自增强 alpha 而非择时。

**当前数据管道与网站的进攻仓均使用拼接口径**（`fetch_data.py` 拉取 `etf_159552*.csv`，
`export_json.py` 在 2024-06-28 处拼接；`data.json` 保留 `etf1000/etf1000_hfq` 作超额基准）。

## 防守仓切换：510880 红利 → 512890 红利低波
510880（上证红利指数）纯按股息率加权，煤炭等强周期股权重过高；512890（中证红利低波动
指数 H30269）增加低波动筛选，行业更分散、防守属性更纯。同一方案C 信号、同一窗口
（2019-01-18 512890上市起 ~ 2026-08，含双边万1佣金）对比：

| 组合 | 累计收益 | 年化 | 最大回撤 | 换仓次数 |
|---|---|---|---|---|
| 512100 + 512890 红利低波 | 523.3% | 27.40% | -20.2% | 129 |
| 512100 + 510880 红利 | 386.3% | 23.28% | -20.3% | 129 |
| 512890 持有 | 130.9% | 11.71% | -16.5% | - |
| 510880 持有 | 76.4% | 7.80% | -20.3% | - |

**当前数据管道与网站均使用 512890**（`fetch_data.py` 拉取 `etf_512890_hfq.csv`，
网站回测窗口因此从 2019-01-18 起算）。旧文件 `data/etf_510880*.csv` 保留作历史对照，
不再更新。

## 数据源（全部通达信通道）

- 平均股价 880003：pytdx `get_index_bars`
- ETF 后复权：pytdx 原始K线 + `get_xdxr_info` 除权除息记录自行复权
  （512100 修正 1 次份额合并 + 2 次分红；512890 修正 1 次分红；
  经验证比东财/腾讯的基金复权因子更准确）
- 备用通道：东财 / 腾讯后复权接口（TDX 不可用时自动切换）

## 文件结构

```
fetch_data.py        # 数据拉取（TDX主通道 + 东财/腾讯备用；含159552深圳市场）
backtest.py          # 回测引擎（通达信EMA口径MACD + 拐点信号 + 轮动回测）
compare.py           # A/B 方案十年对比
compare_variants.py  # 变体对比：2000指数/ETF进攻腿、防守腿择优、159552增强对比
recent_2y.py         # 近2年回测 + 买卖点标注图
export_json.py       # 导出网站数据 site/data.json
run_backtest.py      # 单次回测入口
fetch_avg_compute.py # 备选：从全市场个股自行合成平均股价
optimize.py          # 方案C 参数寻优（网格搜索 MACD 参数/信号类型/买卖阈值）
site/index.html      # 监控页面（ECharts 已本地化，可离线）
server.py            # 网站服务器（静态文件 + /api/update 触发数据更新）
run_server.pyw       # server.py 的无窗口启动引导（供计划任务/启动.bat 调用）
启动.bat             # 启动网站 http://127.0.0.1:8001/（经计划任务无窗口后台运行）
更新数据.bat         # 每日收盘后更新数据并重新导出
register_tasks.ps1   # 注册计划任务：ETFRotationWeb 开机自启 + ETFRotationDataUpdate 工作日 15:10 更新
```

开机自启由计划任务 `ETFRotationWeb` 实现：登录时以 base 解释器的 `pythonw.exe`
运行 `run_server.pyw`，全程无窗口，关闭任何终端都不会影响网站；
勿改用 `.venv\Scripts\pythonw.exe`（uv 转发器会拉起带终端窗口的 python.exe 子进程）。
